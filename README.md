# KaloriLens AI
1. Instal Node.js 18+.
2. Ekstrak ZIP, lalu buka terminal di folder proyek.
3. Jalankan `npm install`.
4. Salin `.env.example` menjadi `.env`.
5. Isi `GEMINI_API_KEY` dari Google AI Studio.
6. Jalankan `npm start`.
7. Buka `http://localhost:3000`.

API key disimpan di backend, bukan di browser. Hasil nutrisi adalah estimasi visual.
